# ReactJS - Hello World

## Task
A basic ReactJS application that displays:

**Hello, World!**

## How to run

1. Open the project folder in VS Code.
2. Open a terminal in the project folder.
3. Run:
   `npm install`
4. Then run:
   `npm run dev`
5. Open the local URL shown by Vite in the browser.

## Submission
`node_modules` is intentionally not included. Run `npm install` before testing locally.
