# Simple Web Server with Node.js

## Objective
A basic web server created using Node.js built-in `http` module.

## Routes
- `/home` - Home page
- `/about` - About page
- `/contact` - Contact page
- Any invalid route - Custom 404 page

## Run
1. Install Node.js.
2. Open this folder in VS Code.
3. Open the terminal.
4. Run:

```bash
node server.js
```

5. Open `http://localhost:3000/home` in the browser.

## Requirements covered
- Node.js HTTP server
- Port 3000
- Three HTML pages
- Route handling
- HTTP 200, 404 and 500 responses
- Asynchronous file reading
- Basic CSS styling
- Custom 404 page
