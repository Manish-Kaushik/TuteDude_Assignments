# OmniFood Responsive Landing Page

A responsive single-page food-delivery landing page built with HTML5, CSS3 and a small JavaScript mobile navigation toggle.

## Project sections
- Header + hero banner
- How It Works
- Our Cities
- Customer testimonials
- Pricing plans
- Footer

## How to run
Open `index.html` directly in a browser. No backend or build process is required.

## Responsive breakpoints
- Desktop: 1200px and above
- Tablet: up to 834px
- Mobile: up to 600px, with an additional compact layout at 390px

## Files
- `index.html` — page structure
- `style.css` — layout, typography, colors and responsive styling
- `script.js` — mobile navigation toggle
- `assets/` — local SVG illustrations and icons

## Notes
The page is designed to reproduce the structure, spacing, colors and visual flow shown in the assignment reference while remaining responsive and usable on smaller screens.
