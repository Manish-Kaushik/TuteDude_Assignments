# Task 18 - JavaScript DOM and Event Handling

## Objective
Create a simple interactive webpage using HTML, CSS and JavaScript DOM event handling.

## Features
- Header initially displays "Hello".
- Four boxes display Red, Blue, Green and Yellow.
- Clicking a box changes its background colour to the colour written in that box.
- User can enter a name in the input field.
- Clicking "Greet User" changes the header to "Hello, [name]".
- Uses DOM selection and event listeners.
- Responsive CSS layout.

## Files
- index.html
- style.css
- script.js

## How to Run
Open `index.html` in a web browser.
