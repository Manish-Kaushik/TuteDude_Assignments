# ReactJS Mini Project - Offline Chess Game

## Features
- 8x8 chess board with initial pieces
- Turn-based two-player play
- Legal movement validation for pawns, rooks, knights, bishops, queen and king
- Prevents moves that leave the player's own king in check
- Check and checkmate/stalemate detection
- 10-minute countdown timer for each player
- Standard chess-style move notation
- Captured-piece display
- New Game / reset functionality
- Responsive layout
- No chess library used

## Run
```bash
npm install
npm run dev
```

Open the Vite local URL in a browser.

## Notes
The project intentionally uses plain React and JavaScript for chess rules rather than an external chess library, as required by the task.
