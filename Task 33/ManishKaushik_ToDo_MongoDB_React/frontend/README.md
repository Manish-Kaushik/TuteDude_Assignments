# To-Do React Frontend – Part 2

## Setup
1. Open the `frontend` folder.
2. Run `npm install`.
3. Copy `.env.example` to `.env`.
4. Set `VITE_API_URL` to the backend API URL.
5. Run `npm run dev`.

## Features
- Fetch tasks from Express/MongoDB
- Add a task
- Edit task details
- Mark task complete/incomplete
- Delete a task
- Search tasks
- Loading and error states
- Responsive interface

## API integration
Axios is used to communicate with the backend.
