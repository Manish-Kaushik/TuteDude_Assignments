# Task 34 – Schema Reference Frontend

## Features
- User form
- Post form
- Select a user when creating a post
- POST requests for users and posts
- GET request for posts
- Display populated user information
- Responsive UI

## Setup

```bash
npm install
```

Copy `.env.example` to `.env`:

```text
VITE_API_URL=http://localhost:5000
```

Then run:

```bash
npm run dev
```

The backend must be running at the configured URL.
