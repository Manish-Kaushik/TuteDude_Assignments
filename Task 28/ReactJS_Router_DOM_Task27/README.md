# React Router DOM - Task 27

## Overview
A simple React application demonstrating navigation between multiple React routes using `react-router-dom`.

## Routes
- `/` - Home
- `/dashboard` - Dashboard
- `/login` - Login
- `/signup` - Signup
- `*` - 404 page

## Features
- React Router DOM navigation
- `BrowserRouter`, `Routes`, `Route`
- `NavLink` for active navigation styling
- `Link` for page-to-page navigation without reload
- Responsive layout
- Simple Login and Signup forms
- 404 fallback route

## How to run
1. Open the folder in VS Code.
2. Run `npm install`.
3. Run `npm run dev`.
4. Open the Vite URL in the browser.

## Decisions
The design is intentionally simple and clean because the assignment allows creative freedom. The main focus is demonstrating React Router DOM and navigation between the four required routes.
