# Task 17 - JavaScript Promise-Based Divide Function

## Objective
Create a JavaScript function that performs division using a Promise.

## Features
- Uses an arrow function.
- Returns a Promise.
- Resolves with the division result.
- Rejects when the second number is zero.
- Handles errors using `.catch()`.
- Includes at least five test cases.
- Includes a simple browser interface.
- HTML, CSS and JavaScript are linked properly.

## Test Cases
1. 10 / 2
2. 20 / 5
3. 15 / 3
4. 100 / 4
5. 10 / 0

## How to Run
Open `index.html` in a browser. Open the browser Developer Tools Console to see the test-case output.
