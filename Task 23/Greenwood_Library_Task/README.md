# Greenwood Library Website

## Project
A simple, responsive Greenwood Public Library landing page made according to the assignment.

## Run
Open `index.html` in a browser. Tailwind CSS is loaded through the official Tailwind CDN, so internet access is required.

## Included
- Sticky blurred navigation
- Responsive mobile menu
- Editorial hero section with CTA buttons
- 4-column statistics row
- 6 interactive library section cards
- 2x2 responsive image gallery with zoom-on-hover
- Asymmetrical bento values grid
- Two-column About text on larger screens
- Membership cards with Popular badge
- Testimonial section with grayscale hover effect
- Contact CTA block
- 4-column responsive events grid
- Multi-column footer
- Tailwind transitions, hover states, group effects, max-width containers, and responsive utilities

## Restrictions followed
- HTML + Tailwind CSS CDN
- No external CSS framework
- No custom font
- Minimal JavaScript only for mobile navigation
