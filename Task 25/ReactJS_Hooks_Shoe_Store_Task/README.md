# ReactJS Hooks - Shoe Store

## Task
A simple React shoe store demonstrating the React `useState` hook.

## Features
- Displays a collection of shoes with name, price and image.
- Add shoes to the shopping cart.
- Adding the same shoe increases its quantity.
- Decrease/remove an item using the minus button.
- Shows quantity and price for cart items.
- Calculates and displays the cart total.
- Responsive layout for smaller screens.

## How to run
1. Open the project folder in VS Code.
2. Open a terminal.
3. Run `npm install`.
4. Run `npm run dev`.
5. Open the Vite URL shown in the terminal.

## Main React concept
The cart is managed with React's `useState` hook.

## Submission
`node_modules` is intentionally not included. Run `npm install` before testing.
