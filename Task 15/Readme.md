# Task 15 - JavaScript Arrays and Functions

This project demonstrates JavaScript arrays and different types of functions.

Operations:
- Find the maximum number in an array
- Calculate the sum of all array elements
- Count the odd numbers in an array
- Display all results using console.log()

Test array:
[4, 8, 2, 11, 6, 7, 10]

Expected results:
Maximum number: 11
Sum of all elements: 48
Count of odd numbers: 2
