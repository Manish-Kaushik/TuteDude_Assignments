# Task 19 - JavaScript DOM Service Booking Web App

## Objective
Create a service browsing and booking web application using HTML, CSS and JavaScript DOM manipulation.

## Features
- Navigation bar with logo, links, username and logout button.
- Left section for dynamically added cart items.
- Right section displaying available services.
- Service name, image and price.
- Skip Item and Add Item buttons.
- Dynamic cart updates using JavaScript DOM methods.
- Total amount updates whenever an item is added or removed.
- Booking form with name, email and phone fields.
- Book Now validation.
- Responsive layout for smaller screens.

## Files
- index.html
- style.css
- script.js
- Readme.md

## How to Run
Open `index.html` in a browser. An internet connection is recommended because the service images are loaded from external image URLs.
