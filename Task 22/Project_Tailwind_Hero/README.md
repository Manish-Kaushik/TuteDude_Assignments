# Project — Tailwind Hero Landing Page

## Overview
A responsive hero landing page built with HTML and Tailwind CSS CDN. It demonstrates:
- Sticky navigation
- Gradient hero background
- Centered headline and CTA buttons
- Relative/absolute positioning
- Dashboard preview
- Floating information cards
- Fixed chat widget
- Responsive mobile navigation

## How to run
Open `index.html` directly in a browser. An internet connection is needed for the Tailwind CSS CDN.

## Files
- `index.html` — page structure and minimal mobile-menu JavaScript
- `assets/dashboard.svg` — dashboard preview
- `assets/avatar-1.svg`, `avatar-2.svg`, `avatar-3.svg` — team avatars

## Tailwind utilities demonstrated
`sticky`, `top-0`, `z-50`, `relative`, `absolute`, `fixed`, `bottom-6`, `right-6`, spacing utilities, responsive breakpoints, gradients, shadows, and color utilities.

## Responsive behavior
- Desktop: full navigation and floating cards
- Tablet: responsive two-button layout and resized dashboard
- Mobile: stacked navigation menu, responsive typography, no horizontal scrolling
